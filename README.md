# RestauranteAPP

App Android (MVVM) para gestión de restaurante: mesas, caja, facturación.

## Requisitos
- Android Studio Hedgehog+ (o más nuevo)
- JDK 17
- SDK Android 24+
- Cuenta Firebase (copiar `app/google-services.json` localmente **sin** subirlo al repo)

## Cómo compilar
1. Clonar el repo
2. Abrir en Android Studio
3. Poner `google-services.json` en `app/`
4. Run ▶️

## Estructura
- `app/src/main/java/com.caferaquielita.restauranteapp/...`
  - `activities/`
  - `viewmodels/`
  - `repositories/`
  - `models/`

## Notas
